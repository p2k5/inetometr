## Краткая архитектура и способ запуска
- **FastAPI приложение** (`src/inetometr/server.py`) с lifespan-менеджером
- **Хранение данных**: SQLite через `src/inetometr/data_store.py` (мигрировано из JSON Lines)
- **Endpoints**:
  - `GET /` - HTML тест скорости
  - `GET /admin` - панель администратора (Bearer токен)
  - `GET /api/status` - статус сервера + IP + пинг
  - `POST /api/speed` - сохранение замеров
  - `GET /api/history` - история измерений
  - `GET /download?mb=N` - N-МБ файл для тестов
  - `POST /upload` - endpoint для загрузки
  - `GET /health` - проверка живости
  - `GET /metrics` - Prometheus метрики
  - `GET /api/export/csv` - CSV экспорт
  - `WebSocket /ws/metrics` - реальное время метрик
- **Запуск**: `INETOMETR_ADMIN_TOKEN=token uv run python -m inetometr.server`
- **Docker**: многоступенчатая сборка, healthcheck, volumes для данных
- **CI/CD**: GitHub Actions workflow с тестами, линтинг, сборкой Docker образа
